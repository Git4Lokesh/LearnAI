% ── Slide 3: The Problem ────────────────────────────────────
\begin{frame}{The Problem -- A Broken Feedback Loop}
  \small
  Coaching centers, schools, and institutes test constantly---but only see \textbf{final MCQ scores}. The diagnostic layer is completely missing.

  \bspace
  \begin{itemize}
    \setlength\itemsep{0.5em}
    \item \textbf{\textcolor{LearnRed}{The Analytics Blindspot:}} A teacher with 500+ students cannot manually analyze \emph{why} a cohort is failing. They see scores, not root causes.

    \item \textbf{\textcolor{LearnRed}{Silent Strugglers:}} Students who guess correctly or take 3$\times$ too long go \emph{completely unnoticed}. Traditional grading rewards luck, not understanding.

    \item \textbf{\textcolor{LearnRed}{Hidden Prerequisites:}} A student fails ``Projectile Motion'' because of a hidden backlog in ``Vectors''---traditional tools cannot map these dependency chains.

    \item \textbf{\textcolor{LearnRed}{Universal Pain:}} This isn't just coaching centers. \textbf{Every CBSE/ICSE school with 11th--12th science}, every integrated school, every institute preparing students for competitive exams faces the same blind spot.
  \end{itemize}
\end{frame}

% ── Slide 4: The Solution ───────────────────────────────────
\begin{frame}{The Solution -- Pedagogy-as-a-Service (PaaS)}
  A \textbf{B2B Learning OS} powered by \textbf{Bayesian Knowledge Tracing (BKT)} and a proprietary \textbf{Hierarchical Knowledge Graph}.

  \bspace
  \begin{itemize}
    \setlength\itemsep{0.5em}
    \item \textbf{Massive Knowledge Graph:} Visually maps \textbf{73 JEE chapters} and \textbf{221 sub-concepts} exactly to the NTA syllabus. Extensible to NEET, boards, and custom curricula.

    \item \textbf{Transparent Mastery:} Nodes dynamically turn \textcolor{LearnGreen}{\textbf{Green}} (Mastered), \textcolor{LearnYellow}{\textbf{Yellow}} (In Progress), or \textcolor{LearnRed}{\textbf{Red}} (Weak) based on real student data.

    \item \textbf{BKT State Update:} Dynamically calculates mastery probability accounting for question difficulty, guessing, slipping, and time-taken.

    \item \textbf{BKT-Aware AI Tutor:} Our LLM reads the student's \emph{live} mastery state---weak concepts, prerequisite gaps, confidence scores---to generate progressive, personalized hints. The AI \textbf{knows what the student doesn't know}.
  \end{itemize}
\end{frame}

% ── Slide 5a: Core IP ───────────────────────────────────────
\begin{frame}{Core IP \& Technology Stack}
  Enterprise-grade architecture built to scale across \textbf{hundreds of institutes}.

  \bspace
  \begin{itemize}
    \setlength\itemsep{0.5em}
    \item \textbf{Adaptive Learning Engine:} Custom Python FastAPI microservice using the \textbf{Expectation-Maximization (EM)} algorithm to learn optimal BKT parameters from student responses.

    \item \textbf{Mastery Tracking:} \emph{Mastery decay} (models forgetting over time) + \emph{time-weighted updates} (fast correct answers boost mastery more).

    \item \textbf{Prerequisite Diagnosis Engine:} Combines decayed mastery, confidence, recency, and accuracy into readiness scores. Generates optimal \textbf{10-step study paths} with explanations.

    \item \textbf{AI Layer:} A \textbf{BKT-aware AI tutor} powered by Gemini 2.5 Flash with deep context injection. The LLM reads the student's \emph{live mastery state} from the BKT engine---their weak concepts, prerequisite gaps, and confidence levels---to generate truly personalized, progressive hints rather than generic answers. This stateful approach is architecturally unique: the AI \emph{knows what the student doesn't know}.
  \end{itemize}
\end{frame}
